# Proxy Protocol v2 (PPv2) 支持

OptiRoute 在数据转发链路中支持注入与剥离标准 **Proxy Protocol v2** 包头, 用于在多层代理后保留客户端真实 IP。

## 作用

- **Edge 节点** 转发流量至源站时, 在 comm_secret 密钥握手之后、业务数据之前注入 PPv2 包头, 携带客户端真实 IP 和端口
- **Server Agent** 解析并剥离该包头, 提取客户端真实 IP, 将原始数据透传给第三方服务端
- 可选向上游注入: `forward_real_ip` 配置开启时, Server Agent 可再次注入 PPv2 包头传递客户端真实 IP (需上游支持)

## 包头结构

PPv2 包头由 **固定 16 字节头部 + 变长地址数据** 构成:

| 偏移 | 长度 | 内容 |
|------|------|------|
| 0 | 12 | 签名 `\x0D\x0A\x0D\x0A\x00\x0D\x0A\x51\x55\x49\x54\x0A` (`\r\n\r\n\0\r\nQUIT\n`) |
| 12 | 1 | 命令字节 `0x21` (version=2, command=PROXY) |
| 13 | 1 | 地址族/协议字节 (`0x11`=IPv4/TCP, `0x21`=IPv6/TCP) |
| 14 | 2 | 地址数据长度 (IPv4=12, IPv6=36) |
| 16 | 变长 | 源地址 + 目的地址 + 源端口 + 目的端口 |

### IPv4/TCP (28 字节)

| 偏移 | 长度 | 内容 |
|------|------|------|
| 16 | 4 | 源 IPv4 |
| 20 | 4 | 目的 IPv4 |
| 24 | 2 | 源端口 |
| 26 | 2 | 目的端口 |

### IPv6/TCP (52 字节)

| 偏移 | 长度 | 内容 |
|------|------|------|
| 16 | 16 | 源 IPv6 |
| 32 | 16 | 目的 IPv6 |
| 48 | 2 | 源端口 |
| 50 | 2 | 目的端口 |

## 配置

| 配置项 | 角色 | 说明 |
|--------|------|------|
| `log_real_ip` | server | 是否在日志中记录客户端真实 IP (从 PPv2 包头提取) |
| `forward_real_ip` | server | 是否向上游注入 PPv2 包头以传递客户端真实 IP (需上游支持) |

## 安全说明

- 包头按地址族自动选择格式: 客户端 IPv4 生成 28 字节包头, IPv6 生成 52 字节包头
- Server Agent 校验 12 字节签名, 签名不匹配即拒绝连接 (拒绝非 PPv2 流量; 签名是公开魔数, 不构成防伪, 真正的防线是连接建立前的 comm_secret 密钥校验)
- 仅支持 `0x21` (PROXY 命令) 与 TCP 协议族
- 校验地址族与长度字段一致性 (IPv4=12 字节, IPv6=36 字节), 畸形包头拒绝解析
